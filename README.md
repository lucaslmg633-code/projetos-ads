# Projetos Acadêmicos — Análise e Desenvolvimento de Sistemas (UBC)

Repositório dedicado ao armazenamento de exercícios, experimentos e protótipos desenvolvidos ao longo da graduação em **Análise e Desenvolvimento de Sistemas** no Centro Universitário Braz Cubas.

---

## 📂 Estrutura e Projetos

### 1. `jogo-cobrinha/` — Jogo da Cobrinha Web
* **Período:** 1º Semestre / 2026
* **Tecnologias:** HTML5, CSS3, JavaScript
* **Descrição:** Implementação clássica do jogo *Snake* executada diretamente no navegador, aplicando lógica de programação, manipulação de Canvas/DOM, controle de colisão e sistema de pontuação.

### 2. `gerenciador-tarefas-cli/` — Gerenciador de Tarefas em Python
* **Período:** 1º Semestre / 2026
* **Tecnologias:** Python 3
* **Descrição:** Script em linha de comando (CLI) para cadastro, listagem e controle de tarefas diárias, focado em estruturas de dados, lógica condicional e organização de fluxo em Python.

---

## 🚀 Como Executar

* **Jogo da Cobrinha:** Acesse a pasta `jogo-cobrinha/` e abra o arquivo `snake.html` em qualquer navegador web.
* **Gerenciador de Tarefas:** Acesse a pasta `gerenciador-tarefas-cli/` pelo terminal e execute:
